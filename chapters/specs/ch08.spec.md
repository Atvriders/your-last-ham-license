### Beat 1 — Waveforms and conversion: Fourier, RMS, PEP, ADC/DAC (E8A)
- Fourier analysis shows a square wave is a sine plus its **odd harmonics** (E8A01); time domain = amplitude at different times (E8A03); a true-RMS meter measures RMS for sinusoidal and non-sinusoidal signals alike (E8A05).
- The conversion craft: successive approximation is a type of A/D conversion (E8A02); dither = a small amount of noise added to the input to reduce quantization noise (E8A04); flash (direct) converters serve SDRs because their very high speed digitizes high frequencies (E8A08); the DAC output low-pass filter removes spurious sampling artifacts (E8A10); total harmonic distortion measures ADC quality (E8A11 — PEP, reciprocal mixing, and power factor are borrowed RF terms as distractors). An 8-bit ADC encodes 2⁸ = 256 levels (E8A09 — the "8" distractor confuses bits with levels).
- PEP at depth: unprocessed SSB phone has a PEP-to-average ratio of about **2.5:1**, determined by speech characteristics (E8A06, E8A07 — not 25:1; not set by carrier suppression or amplifier gain). Figure: `{{fig:ch08-sampling-aliasing}}`.
- Vocabulary: Fourier analysis, successive approximation, flash/direct conversion, dither, quantization noise, true RMS, total harmonic distortion, peak envelope power.

### Beat 2 — Modulation index, deviation ratio, multiplexing (E8B)
- The definitions: modulation index = frequency deviation ÷ modulating frequency (E8B01); a phase-modulated emission's index does not depend on the RF carrier frequency (E8B02); deviation ratio = **maximum** carrier deviation ÷ **highest** modulating frequency — the worst-case sibling of the index (E8B09).
- The arithmetic (every calc question offers the inverted ratio as a distractor — divide deviation BY modulating frequency, never the reverse): E8B03: 3000/1000 = **3**; E8B04: 6000/2000 = **3** (both key to 3 — and E8B04's stem carries the pool's published interior double space, preserved byte-exact in quotes); E8B05: 5 kHz/3 kHz = **1.67**; E8B06: 7.5 kHz/3.5 kHz = **2.14**.
- Multiplexing: OFDM = digital modulation using subcarriers at frequencies chosen to avoid intersymbol interference, used for amateur digital modes (E8B07, E8B08); FDM divides the signal into separate frequency bands each carrying a different data stream (E8B10); digital TDM gives two or more signals discrete time slots of one transmission (E8B11).
- Figure: `{{fig:ch08-modulation-index}}`.
- Vocabulary: modulation index, deviation ratio, OFDM, subcarrier, intersymbol interference, frequency-division multiplexing, time-division multiplexing.

### Beat 3 — Digital signals: modes, codes, bandwidths (E8C)
- QAM transmits data by modulating the amplitude of two carriers of the same frequency 90° out of phase (E8C01); a constellation diagram shows the possible phase and amplitude states for each symbol (E8C13).
- Symbol rate = the rate at which the waveform changes to convey information — and symbol rate and baud are **the same thing** (E8C02, E8C11 — the halving/doubling distractors). Changing PSK phase at the RF zero crossing minimizes bandwidth (E8C03); PSK31 uses sinusoidal data pulses for the same reason (E8C04).
- The bandwidth numbers: CW bandwidth is set by keying speed and rise/fall shape — approximately 4 × WPM, so 13 WPM ≈ 52 Hz (E8C05; not power, not modulation index — E8C12); an FT8 signal's bandwidth is 50 Hz (E8C06); FSK/data bandwidth ≈ (1.2 × shift) + baud — 1.2 × 4800 + 9600 = 15.36 kHz (E8C07 — the raw shift and baud values are the distractors).
- Codes and error handling: ARQ corrects errors by requesting retransmission when errors are detected (E8C08); Gray code changes only one bit between sequential values (E8C09); a more efficient digital code raises the data rate without more bandwidth (E8C10). Mesh nodes have IP addresses and form the network via discovery and link-establishment protocols — not store-and-forward digipeating (E8C14, E8C15).
- Vocabulary: QAM, QPSK, symbol rate, baud, constellation diagram, PSK31, sinusoidal data pulses, ARQ, Gray code, FT8, mesh network, link establishment.

### Beat 4 — Keying defects and spread spectrum (E8D)
- Key clicks: extremely short rise and fall times on CW generate them (E8D04); the cure is **increasing** the rise and fall times (E8D05 — not output filters).
- Spread spectrum: the receiver suppresses signals not using the spreading algorithm — hence the interference resistance (E8D01); direct sequence uses a high-speed binary bit stream to shift the **phase** of an RF carrier (E8D02); frequency hopping rapidly varies the carrier **frequency** per a pseudorandom sequence (E8D03). The definitions appear swapped in each other's distractors — "phase" = direct sequence, "frequency" = hopping. Figure: `{{fig:ch08-spread-spectrum}}`.
- Signal quality: parity bits let some error types be **detected**, not corrected (E8D06); the common cause of AFSK overmodulation is excessive transmit audio level, evaluated as intermodulation distortion (E8D07, E8D08); the acceptable maximum IMD for an idling PSK signal is about **−30 dB** (E8D09 — negative, against the +5/+10/+15 dB distractors).
- The character codes: Baudot carries 5 data bits per character with 2 letters/figures shift codes (E8D10 — the 4/6/7-bit distractors surround the keyed 5); ASCII uses 7 or 8 bits with no shift codes and can transmit both upper- and lowercase (E8D11).
- Vocabulary: spread spectrum, direct sequence, frequency hopping, pseudorandom sequence, key clicks, parity bit, AFSK, intermodulation distortion, Baudot, ASCII, letters/figures shift.

## 5. Worked examples (several `> **Worked example:**` blockquotes — pool numbers exactly)

- Index vs deviation ratio: "Your FM transmitter deviates 3 kHz on a 1 kHz tone: modulation index = Δf ÷ f_mod = 3000/1000 = **3** (E8B03). At 6 kHz deviation on a 2 kHz tone the index is again 6000/2000 = **3** (E8B04). Now take the maxima: 5 kHz maximum deviation with a 3 kHz highest modulating frequency → deviation ratio = 5/3 = **1.67** (E8B05); 7.5/3.5 = **2.14** (E8B06). Every wrong answer on these four is the ratio flipped upside down."
- CW bandwidth: "The pool's rule of thumb: bandwidth ≈ 4 × WPM. At 13 WPM that's 4 × 13 ≈ **52 Hz** (E8C05) — keying speed and rise/fall shape set it, not power and not a modulation index (E8C12)."
- Data bandwidth: "A 9600-baud FSK signal with a 4800 Hz shift: BW ≈ (1.2 × shift) + baud = 1.2 × 4800 + 9600 = 5760 + 9600 = **15.36 kHz** (E8C07). And FT8 fits a whole QSO into **50 Hz** (E8C06) — the narrowest mode in the list."
- PEP and average: "Unprocessed SSB speech runs a PEP-to-average ratio of about 2.5:1 (E8A06): a 100 W PEP signal averages about 40 W over the syllables — set by speech characteristics, not by anything in your transmitter (E8A07)."
- Levels vs bits: "An 8-bit ADC encodes 2⁸ = **256** input levels (E8A09) — 8 is the bit count, not the level count."
